# Security policy

## Supported versions

Security fixes are applied to the latest published release. Older releases may not receive patches.

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** flow to submit a private report. Do not open a public issue for a suspected vulnerability and do not include live ANAF credentials, tokens, cookies, authorization codes, raw callback URLs, invoice documents, SMTP credentials or administrator passwords.

Include a concise impact description, affected version, sanitized reproduction steps and any proposed remediation. Please allow time to investigate before publicly disclosing the issue.

This project has not undergone an independent security audit. Review the deployment and data-protection requirements for your environment before using it with production invoice data.

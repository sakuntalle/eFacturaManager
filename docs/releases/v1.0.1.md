## Highlights

- Added a dedicated non-developer installation guide for running released images with Docker Desktop.
- Documented the supported `linux/amd64` and `linux/arm64` container platforms and how they map to Windows, macOS and Linux hosts.
- Documented persistent database volumes and the HTTPS setup required for the ANAF OAuth callback.

## Fixes

- The release environment template is now published as `env.release.example`, a stable filename that GitHub preserves when downloading the asset.

## Upgrade notes

- Existing installations can set `EFACTURA_VERSION=1.0.1`, pull the new images and start the stack again.
- Named Docker volumes preserve the database during the upgrade. Do not use `docker compose down -v` unless the stored database and mock data should be permanently deleted.
- Live ANAF installations must continue to include `compose.https.yaml` and use the exact registered HTTPS callback.
